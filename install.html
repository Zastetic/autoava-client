AUTOAVA

Instalar o cliente em 2 passos

O cliente e so uma interface: ele le a sessao que voce ja abriu e conversa com o servidor. Nenhuma senha e digitada aqui.

Passo 1 - mostrar a barra de favoritos

No Chrome ou Edge, aperte Ctrl + Shift + B. A barra aparece embaixo da barra de endereco.

Passo 2 - arrastar o botao para a barra

AutoAVA

Arraste o botao verde para a barra de favoritos. Se preferir, use "Copiar codigo", crie um favorito manual e cole no campo de URL.

Como usar

  1. Abra a plataforma e faca o login normalmente.
  2. Clique no favorito AutoAVA que voce acabou de criar.
  3. O popup aparece no canto da tela: cole a chave e clique em executar.
  4. Esc ou o X fecham o popup.

"Testar aqui" mostra o popup nesta propria pagina (sem sessao, o status fica amarelo).

Se nao funcionar

O favorito precisa ser clicado na pagina da plataforma, com a sessao aberta. Se o favorito nao fizer nada, apague e arraste de novo: favorito criado com codigo quebrado continua quebrado.

Codigo (transparencia)

Tudo que o cliente faz esta abaixo. Nada de senha, nada de tecla registrada.
